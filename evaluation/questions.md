# 검증 질문 세트 (30문항)

- 모든 질문 앞에 `(기준일: 2026년 10월 19일)`을 붙여 입력합니다.
- ★ 표시는 최근 개정 또는 개정 논의가 있었던 항목입니다. 일반 AI가 구법이나 개정안을 현행처럼 답할 가능성이 높아, 환각 차이가 가장 잘 드러나는 문항입니다.
- "정답" 칸은 **AI 답변을 수집하기 전에** 국가법령정보센터 원문으로 직접 확인해 채웁니다. ([채점 방법](methodology.md#3-정답-확정-절차))

## 소득세 — 근로·종합소득 (15문항)

| 번호 | 질문 | 검증 포인트 | 정답 (근거 조문·링크) |
|---|---|---|---|
| Q01 ★ | 2026년 귀속 자녀세액공제는 몇 살 자녀부터 받을 수 있나요? | 본문 연령, 부칙의 연도별 특례, 아동수당법 연계에 따른 출생연도 배제까지 반영했는지 | |
| Q02 ★ | 공제대상 자녀가 3명이면 2026년 귀속 자녀세액공제 금액은 얼마인가요? | 최근 인상된 금액을 반영했는지 | |
| Q03 | 2026년에 둘째 아이를 출산하면 출산·입양 세액공제는 얼마인가요? | 출산 순서별 금액, 자녀수 공제와 별도인지 | |
| Q04 ★ | 6세 이하 자녀가 2명인 근로자가 회사에서 받는 출산·보육수당의 월 비과세 한도는 얼마인가요? | 한도가 근로자 기준인지 자녀 1명당 기준인지, 적용 시기 | |
| Q05 ★ | 초등학교 1학년 자녀의 태권도 학원비도 교육비 세액공제를 받을 수 있나요? | 공제 대상 연령·학년 요건, 적용 시기 | |
| Q06 ★ | 회사에서 받은 출산지원금은 근로소득세가 비과세되나요? | 비과세 요건(지급 시기·횟수·대상 등), 적용 시기 | |
| Q07 ★ | 세대주가 아닌 배우자도 월세 세액공제를 받을 수 있나요? | 허용 여부, 요건, 한도, 적용 시기 | |
| Q08 ★ | 자녀가 2명이면 신용카드 등 소득공제 기본한도가 늘어나나요? | 추가 한도 금액, 총급여 구간별 차이, 근거 법률(조특법) | |
| Q09 | 연금저축과 IRP를 합쳐 연금계좌 세액공제 한도와 공제율은 어떻게 되나요? | 납입 한도, 소득 구간별 공제율 | |
| Q10 | 난임시술비는 의료비 세액공제율이 몇 %인가요? | 일반 의료비와 다른 공제율 | |
| Q11 | 부모님을 부양가족 기본공제 대상으로 올리려면 나이와 소득 요건이 어떻게 되나요? | 연령 요건, 소득금액 요건 | |
| Q12 | 근로자가 받는 식대는 월 얼마까지 비과세인가요? | 현행 한도 | |
| Q13 ★ | 고향사랑기부금 세액공제 한도와 공제율은 어떻게 되나요? | 최근 한도 변경, 구간별 공제율, 근거 법률(조특법) | |
| Q14 ★ | 배당소득 Gross-up(배당가산율)은 현재 몇 %이고 앞으로 바뀌나요? | 현행 비율, 개정 시행 시기와 경과조치 | |
| Q15 | 2026년 귀속 종합소득세 최고세율과 적용 과세표준 구간은? | 최고 구간 기준금액과 세율 | |

### 질문을 바꾸거나 추가할 때

- ★ 문항 비율을 절반 정도로 유지하면 MCP 연결 효과가 잘 드러납니다.
- 정답이 기준일에 따라 달라지는 질문(시행일·적용례가 있는 질문)이 가장 좋은 검증 문항입니다.
- 해석이 갈리는 질문은 정답을 확정하기 어려우므로, 조문으로 정답이 분명한 질문 위주로 구성합니다.
